```java
// 在 GlobalExceptionHandler 中添加
@ExceptionHandler(AccessDeniedException.class)
@ResponseStatus(HttpStatus.FORBIDDEN)
public ResponseEntity<?> handleAccessDeniedException(AccessDeniedException ex) {
    return ResponseEntity.status(HttpStatus.FORBIDDEN).body("Access Denied");
}
```

## 发现的问题及建议

### 高优先级问题

1. **数据库字段长度不足** (影响：居民房产认证功能)
   - 问题：`resident_house.relation` 字段无法存储中文字符
   - 影响：居民无法提交房产认证申请
   - 建议：立即修改字段定义为 `VARCHAR(50) CHARACTER SET utf8mb4`

2. **外键约束导致删除失败** (影响：房产管理功能)
   - 问题：删除房产时触发外键约束
   - 影响：无法删除已有关联数据的房产
   - 建议：实现业务逻辑检查或软删除机制

3. **无效取件码验证缺失** (影响：快递服务功能)
   - 问题：使用无效取件码取件返回成功
   - 影响：可能导致数据不一致或安全漏洞
   - 建议：在服务层添加快递存在性验证

### 中优先级问题

4. **权限错误处理不精确** (影响：用户体验)
   - 问题：权限拒绝返回 500 而非 403
   - 影响：前端无法准确判断错误类型
   - 建议：添加全局异常处理器映射 AccessDeniedException 到 403

### 低优先级问题

5. **错误信息国际化** (影响：多语言支持)
   - 问题：错误信息为英文或技术术语
   - 建议：实现错误消息的国际化支持
